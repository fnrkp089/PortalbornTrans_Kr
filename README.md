# Portalborn 한국어 패치

[Portalborn](https://store.steampowered.com/app/4815720) (90년대풍 판타지 텍스트 머드)의 비공식 한국어 패치입니다.

## 사용법

1. 게임을 끕니다.
2. 릴리즈에서 `Portalborn_KR_Patcher-*.zip`을 받아 압축을 풉니다.
3. `Portalborn_KR_Patcher.cmd`를 더블클릭 → **한국어 패치 적용**.
4. 게임을 켜면 한국어로 나옵니다. 화면의 🌐 언어 버튼으로 English와 바꿀 수 있습니다.

- 스팀 설치 경로는 자동으로 찾습니다. UMPC 같은 작은 화면에서도 버튼까지 한 화면에 들어오게 창이 맞춰집니다.
- 새 번역이 릴리즈되면 패처가 적용할 때 자동으로 받아 씁니다 (해시 확인 후). 인터넷이 안 되면 패처에 든 번역으로 적용합니다.
- 스팀이 게임을 업데이트하면 패치가 풀립니다. 패처로 다시 적용하세요.
- 게임이 번역보다 새 버전이면, 새로 생긴 문장은 번역 업데이트 전까지 중국어로 나올 수 있습니다.

## 한국어 명령어

`북` `남` `동` `서` `위` `아래`, `보기`, `가방`, `스킬`, `도움말`, `공격 [대상]`, `시전 [스킬]` 등을 한국어로 칠 수 있습니다.
영어 명령어도 그대로 됩니다.
- 되돌리기: 패처의 **원본 복원**, 또는 스팀 → 속성 → 설치된 파일 → 게임 파일 무결성 검사.

## 동작 방식

게임은 영어와 중국어(간체)를 지원합니다. 패처는 게임 파일 `resources/app.asar` 안의 중국어 문장을
한국어로 바꿔 다시 묶습니다. 그래서 게임 안에서 '중국어'를 고르면 한국어가 나옵니다 (패치 후 기본값).

- 바꾸는 게임 파일은 `resources/app.asar` 하나이고, 원본은 게임 폴더의 `kr_patch_backup/`에 보관합니다.
- 패처는 사용자 PC에 있는 게임 파일을 그 자리에서 고치므로, 게임 업데이트 후에도 다시 적용할 수 있습니다.
- 문자열 외에 한국어에 필요한 보정(띄어쓰기, 조사 자동 선택, 한글 검색어 인식, 한글 글꼴)은
  `translation/code_patches.json`에 찾기/바꾸기 목록으로 공개되어 있습니다.
- 직접 만든 실행 파일(exe)은 없습니다. 패처는 Python 소스이며 python.org 공식 Python으로 실행됩니다.

## 구성

| 경로 | 내용 |
|---|---|
| `patcher/` | 패처 소스 (`patcher.py` 창·명령줄, `kopatch.py` 번역 적용, `jstok.py` JS 문자열 찾기, `asar.py` 묶음 파일 읽기·쓰기) |
| `translation/ko_strings.json` | 번역 (중국어 원문 → 한국어) |
| `translation/code_patches.json` | 코드 보정 목록 |
| `translation/glossary.json` | 용어집 |
| `build_package.py` | 배포 패키지 만들기 |

패처 창에는 메이플스토리가 제공한 메이플스토리 서체가 적용되어 있습니다 (저작권 안내: `patcher/Maplestory-LICENSE.txt`).
